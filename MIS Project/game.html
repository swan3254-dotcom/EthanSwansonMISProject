Enhanced Snake Game

This is a challenging version of the classic Snake game! The board is 10x10 squares. The snake wraps around the edges instead of dying on walls. Eat multiple foods (up to 3 on screen at once) to grow. Win by reaching 200 points (eat 20 foods). Speed starts slow but increases every 50 points. High scores are saved locally. Use arrow keys to control the snake.

Snake Game Play

Control the green snake head with arrow keys. Eat the red foods to score 10 points each and grow. Avoid hitting any part of your own body. The game wraps around the board edges, so no wall deaths! Game speeds up every 50 points for increased challenge. Achieve 200 points to win! Restart any time with the button below.
